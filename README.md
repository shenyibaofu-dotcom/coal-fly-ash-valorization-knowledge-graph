# Coal Fly Ash Valorization Knowledge Graph

**Research code accompanying manuscript WM-26-2894**

This repository documents the Python implementation of literature preprocessing, dictionary matching, candidate-triple extraction, V2/V3 decision auditing, weighted knowledge-graph construction, Louvain community analysis, and literature-based pathway evaluation.

> **Availability notice:** The repository currently contains source scripts, an input-file correspondence table, and three derived numerical CSV tables, **not** the underlying bibliographic records, full V2/V3 review tables, frozen 19,177-instance relation table, or original dictionary JSON files. Three non-bibliographic derived CSV datasets are now available in `inputs/`: `KG_2000-2025_Aggregated_Edges_198.csv`, `Fig4d_2000to2025_Evidence_Filtered_Edges.csv`, and `Fig3_3075_aggregates_and_proxy_inputs.csv`. The repository is therefore **not independently executable end-to-end as published**. Files listed under `inputs/` and `dict/` are required for complete execution. Their availability and redistribution are subject to data-source licensing and author review.

## Code modules

| File | Role and scope |
| --- | --- |
| `01_preprocessing.py` | Cleans bibliographic fields, audits duplicates and checks the frozen 3,075-paper corpus. It does not reconstruct every historical search and manual exclusion decision from the original 4,938 records. |
| `02_entity_dictionary_matching.py` | Finds candidate entities using the original terminology dictionaries. Lexical matches are not validated semantic relations. |
| `03_triple_extraction_original_rules.py` | Re-applies the original dictionary/rule-based candidate triple extraction to the final corpus. **Candidate triples are not the final human-reviewed relations.** |
| `04_v2_v3_author_review.py` | Audits *recorded* V2/V3 author decisions and checks the final frozen relation table. It does not independently reproduce the human judgments. |
| `05_final_knowledge_graph.py` | Reconstructs the aggregated core graph from the frozen 19,177 paper-linked relation instances, checks 198 directed relation edges and exports edge/node files. |
| `06_louvain_community_analysis.py` | Reproduces the figure-specific **external association network** (39 nodes, 104 edges; seed 42, five Louvain communities; Q about 0.4684). This is distinct from the 198-edge directed core graph. |
| `07_pathway_evaluation_figures.py` | Rechecks classification, maturity and reporting-proxy inputs and generates selected Fig. 2/3 statistical plots. It does **not** reproduce all 17 original panels pixel-for-pixel. |

`Code_Data_Correspondence.csv` lists the **exact required input filenames**, their original record counts or dictionary counts, and the modules in which they are used. Some referenced inputs have been uploaded under `inputs/`, but **most required author-level input files remain unavailable**. Check the actual repository file list before attempting to run a script.

## Example execution

After obtaining the corresponding permitted `inputs/` and `dict/` files, run from the repository root:

```bash
python 01_preprocessing.py
python 02_entity_dictionary_matching.py
python 03_triple_extraction_original_rules.py
python 04_v2_v3_author_review.py
python 05_final_knowledge_graph.py
python 06_louvain_community_analysis.py
python 07_pathway_evaluation_figures.py
```

Each script writes its own results to `outputs/`. Source-table names and paths must match `Code_Data_Correspondence.csv`.

## Interpretation and validation boundaries

- The analytical corpus comprises 3,075 records from 2000–2025 after author-defined screening; these are not a freely redistributable copy of WoS/Scopus exports.
- The reported 19,177 instances are **paper-linked supports**; 198 is the number of **distinct aggregated directed relation edges**, not 198 extracted papers.
- The external Louvain network and the directed core graph have different inputs and should not be conflated.
- Quantitative cross-checks of file counts and edge weights are not equivalent to independent, source-by-source semantic precision or full-text validation.
- The original author-reviewed decisions cannot be recreated from candidate-extraction code alone.
- No independent random-sample semantic extraction precision is claimed in this repository.
- The source code itself can be inspected, but end-to-end computational reproducibility additionally requires the specified input files and any applicable permissions.
